Hidden Flower Quest

3 parts of Willow Haven have a Hidden Flower, and along with those 3 parts, come 3 different maps. Which world would you like to explore to find the Hidden Flower?

Each part has its own charm.
Moonberry Grove is very pretty in colours with clear waters, but has a lot of secrets.
Whisty Meadows is magical and interactive but is guarded by an Eagle, the Protector of the Meadows.
Dandelight village is a peaceful village in Willow Haven, but it has a very mysterious vibe to it. It's like cracking a code in order to progress
